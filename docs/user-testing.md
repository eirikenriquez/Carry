# Short remote user test

Use the supplied Android app in your own time. We are testing its features,
not religious knowledge. Use fictional situations, not personal information.

## Before starting

Participation is voluntary. You can stop anytime. Do you agree to your responses
being included without your name in coursework and public project documentation?
Yes / No. Continue only with Yes and the required course consent process.

Participant label (e.g. P01): ___  Date: ___  Phone/Android version: ___

First time using Carry: Yes / No.
Target-group fit (Christian, 18–29, optional): Yes / No / Prefer not to say.

Timing is optional. If using a stopwatch, start after understanding each prompt.
Stop when the task's goal is reached. Exclude installation, waiting and form-filling.
If interrupted, note it. Leave unmeasured times as **NM**, not estimates.

## Tasks

1. **Create:** Prepare for a fictional difficult discussion. Choose Scripture and
   save a Carry in category **Practice**, scheduled a few minutes ahead, with an
   if–then plan. Stop when it is saved.
2. **Reflect:** Once that scheduled time has passed, imagine you paused before
   replying. Save a reflection on the same Carry. Stop when it is saved.
3. **Retrieve:** Begin another Carry in category **Practice**. Find its latest
   reflection. Stop when found, without saving the new Carry.

## Research notes

Tasks follow [RUN-01](evaluation.md#criteria-from-milestone-1).
Completion, help and times are self-reported, not independently observed.
SEQ measures perceived ease, not a usability pass. Keep pilot/repeat results separate.
Store consent/contact records privately, not with public results.

SEQ sources: [Sauro and Dumas (2009)](https://doi.org/10.1145/1518701.1518946)
and [Sauro and Lewis (2024), current wording and scale](https://measuringu.com/evolution-of-seq/).
